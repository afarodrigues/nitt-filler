Política de Privacidade do NITT Filler

Última atualização: 5 de novembro de 2026.

Quais dados acessamos

  • Google Drive: os arquivos das pastas indicadas pelo dono da conta (documentos dos casos e modelos de parecer), para gerar os rascunhos, e a pasta de saída, onde gravamos os resultados.
  • Gmail: apenas o envio de e-mails de notificação sobre os pareceres processados. O sistema não lê, apaga nem altera mensagens da caixa de entrada.

Como os dados são usados

Os documentos são processados em um servidor próprio, com um modelo de linguagem executado localmente. Nenhum conteúdo é enviado a serviços de inteligência artificial de terceiros. Os dados são usados exclusivamente para gerar os rascunhos de parecer e as notificações.

Armazenamento

Os pareceres gerados e os relatórios de auditoria ficam no Google Drive do próprio usuário. O servidor guarda apenas cópias temporárias de trabalho e a credencial de acesso (token), protegida e acessível somente aos administradores do sistema.

Compartilhamento

Não vendemos, alugamos nem compartilhamos dados com terceiros. O uso de informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Revogação do acesso

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions. Após a revogação, o sistema deixa de acessar o Drive e de enviar e-mails.
